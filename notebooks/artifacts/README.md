# Legacy notebook artifacts

These files were generated by `notebooks/patients.ipynb` during the original
PIMA logistic-regression workflow.

| File | Purpose |
|---|---|
| `global_model.pkl` | Pickled scikit-learn logistic-regression model from the notebook |
| `scaler.pkl` | Pickled notebook scaler |
| `global_weights.npz` | Federated coefficient and intercept arrays |
| `sample_patients.csv` | Ten test rows saved by the notebook |
| `library_versions.json` | Notebook library versions at export time |

The current `federated_engine.py`, Flask app, and experiment harness do not read
these files. They are retained only as a reference to the earlier notebook path.
